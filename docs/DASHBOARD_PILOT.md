## Próba instalacji na innym Windows bez Pythona
Artefakt: dostarczony ZIP i jego SHA-256.
Zależność: zgoda właściciela komputera i lokalny eksport bez zbędnych danych osobowych.
1. Rozpakuj cały katalog, uruchom EXE, otwórz lokalny adres.
2. Uruchom demo; sprawdź 1250,00 PLN / 7 / 178,57 PLN.
3. Zadeklaruj kompletność 31.08–13.09.2026; sprawdź +25,0%.
4. Wygeneruj PDF, obejrzyj go, zakończ serwer i uruchom ponownie.
DoD: wszystkie cztery kroki bez instalacji Pythona i pomocy autora.
